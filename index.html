Overview

The Problem

The ever-increasing network demands of modern high density venues have led to the emergence of what are now called "Smart Environments". To meet these demands, the industry has moved away from the traditional cloud model and towards Multi-Access Edge Computing, as standardized by ETSI.

By moving compute away from a centralized server to the edge of the network, MEC delivers the performance and control these environments require, at the cost of the attack surface becoming significantly harder to control.

This project addresses that gap by designing and implementing a log and metrics-based security monitoring framework that, by collecting and centralizing logs and metrics from across the stack, provides operators with meaningful visibility into the network, generating alerts on suspicious activity and automating defensive responses where applicable.

It does not stand as a standalone security solution, but rather as a single component of a broader security plan.

01

Traffic Segmentation — Strict isolation between public user traffic and critical sensor data via micro-segmentation.

02

Edge Hardening — Security controls on edge nodes to prevent lateral movement attacks.

03

Security Command Center — Centralized SIEM ingesting logs from all edge nodes for real-time visibility.

04

Threat Detection & Response — Automated rules to detect and block DDoS, unauthorized access, and intrusion attempts.
